# Decisions Page — Claude Design Revision Prompt

Produced 2026-07-08 by a 10-persona senior-media-buyer panel (individual eval -> facilitator synthesis -> round-table reactions/votes -> design-lead convergence). Deliverable = the revision prompt at the bottom, to hand to Claude Design.

## Converged direction
The panel converges on a single principle: the page must open as work, not weather. We resolve the radical-simplicity vs power-user-density split not by choosing a camp but by separating layers — a calm, bounded, opinionated DEFAULT STATE (Emre/Tom/Marcus land on their "few things today") sitting on top of a fully powerful, sortable, exportable data substrate (Aisha/Dane/Priya/Ken/Lena get their instrument panel), with saved views as the bridge that persists each operator's calibration. The three stacked context bands (Pulse, Digest, Readiness) collapse into one default-collapsed "morning brief" off the scroll path, and every duplicated status fact (staleness, label coverage) collapses to a single canonical affordance, with only one small always-on as-of/staleness stamp surviving for trust. Money-at-stake stays the default sort and the per-row figure, but stops being the sole gravity well — Ravi's DR-bias critique is resolved by adding funnel-role as a sortable column/grouping facet, un-collapsing Non-sales by default, and letting brand-safety severity escalate a row regardless of dollars; nothing is ever silently hidden (a hidden row is worse than a dense one), so aggressive filtering leaves a one-click "+$X / N rows below threshold" suppression receipt. Creatives stay first-class ON the page as a lifecycle-grouped lens over the same campaign→ad set→creative tree (the tree replaces the XOR radio), reachable via a count-chip that is the door IN, never a bounce OUT to Creative Studio. Cross-engine ranking is honored only as an opt-in dollars-summed sort across collapsed parents with a visible source tag and zero fabricated blended confidence. The single biggest calm-at-scale lever the panel surfaced beyond spatial roll-up is TEMPORAL: default the queue to what changed since last session, auto-settling stable rows into a collapsed tail, so a 300-row account reads as the dozen things that actually moved.

## Resolved tensions
- Where creative decisions live → RESOLVED: keep them first-class ON the Decisions page as a creative lifecycle lens (Winners/Fatigue/Testing/Diagnose) over the shared hierarchy, with a count-chip that expands/focuses IN-place (never routes out to Creative Studio for the core cut/scale/refresh call). Rationale: for ASC/broad and high-test operators the creative IS the account, but pod owner-splitting is solved by per-row claim state, not by exile.
- Money-at-stake as master sort → RESOLVED: stays the DEFAULT row order and the per-row number, but is no longer the sole axis — add funnel-role as a sortable column + grouping facet, ship Non-sales expanded, and let brand-safety/policy severity escalate into Action Now regardless of dollars. Rationale: money-at-stake is the trusted spine, but sole-sort + always-on min-spend + collapsed-Non-sales compound into a DR/last-click blind spot; sort by it, don't let it decide what exists.
- Calm-at-scale meaning (data grid vs fewer things) → RESOLVED: a sortable, exportable, column-driven data grid IS the substrate (multi-sort, CSV, verdict + numeric-threshold filters, raw metrics never abstracted), but it DEFAULTS to a bounded top-N-by-money view with roll-up subtotal rows and a 'my few things' feel. Rationale: never buy calm by taking numbers away; buy it with user-controlled density, collapse, and an opinionated default — a summary augments the numbers, never replaces them.
- Cross-engine ranking → RESOLVED: default stays engine-segmented; offer an OPT-IN merged sort that ranks by dollars summed across collapsed parents with a persistent source tag and NO fabricated cross-engine confidence rank. Rationale: dollars are a shared unit and mergeable; confidence scales are per-engine and blending them fabricates a truth the engine never computed.
- Level/hierarchy model → RESOLVED: replace the Campaigns-XOR-Ad-sets radio with ONE expandable campaign→ad set→creative tree (kills the mode-swap that severs parent-child context), and add a creative-only view as a saved lens/focus mode OVER that tree — not a parallel hierarchy. Rationale: the tree is load-bearing for drill; the creative flip is a lens for the operators who live there.
- Home for ambient context → RESOLVED: single default-collapsed 'morning brief' line/drawer off the scroll path (NOT a persistent 236px rail), opened once with coffee; keep exactly one small always-on as-of/staleness stamp; gate the readiness/label-coverage nag behind actual write-intent (surface in the inspector when acting). Rationale: Pulse/Digest/Readiness is weather not the job; a permanent rail just relocates the clutter and steals grid width; label coverage only matters at the moment of write.
- Min-spend floor → RESOLVED: demote from an always-on naked toggle into a saved-view/governed setting, and pair ANY active view-filter with a transparent 'suppression ledger' receipt ('min-spend hid N rows / $X — 3 flagged Awareness/Brand-safety, click to reveal'). Rationale: it's the best noise filter AND the most DR-biased knob; a receipt makes aggressive filtering safe by guaranteeing no deliberately-small test or brand-safety flag is ever silently erased.
- Saved views & ownership → RESOLVED: two tiers — personal saved views as the floor, plus optional lead-locked pod presets that cascade with VISIBLY-flagged personal overrides; add per-row claim/assignee (Mine/Unclaimed/All) as a VIEW filter (never a server filter that hides money), with a 'last touched by X at HH:MM' stamp. All pod/claim UI is entirely hidden on single-operator accounts. Rationale: the page must reopen in each operator's calm state; claim state kills re-triage waste for pods without imposing enterprise machinery on solo users.

# THE REVISION PROMPT (hand this to Claude Design)

GOAL
Revise the existing Adsecute "Meta · Decision Center" (Decisions) surface so it stays CALM and focused even on a large account that has many campaigns AND many ad sets AND hundreds of creatives. This is a REVISION, not a rebuild: preserve the current design language and honesty laws exactly, and restructure the information architecture, default state, and progressive disclosure around them.

KEEP (do not touch, do not "prettify" away)
- The dense-but-clean IBM Plex operator-console language: warm-neutral tokens (canvas #F5F5F3, white cards, ink #1A1C1F/#4A4F56/#7D838C, hairline borders #E4E4E0), semantic colors used sparingly for meaning (danger/caution/positive/info), purple --auto for automation, mono numerics, flat (no heavy shadows), 13px base. Declutter by removing/collapsing/de-duplicating bands and by giving the operator control over density — NEVER by inflating padding into a spacious consumer dashboard.
- The honesty laws, non-negotiable: missing ≠ zero (leave blanks blank, min-spend hides rows rather than zeroing them), no fabricated data, no fabricated cross-engine global/confidence rank, withheld counts on error instead of false zeros, and a visible snapshot as-of / staleness signal. A hidden row is worse than a dense one — nothing may be silently dropped or truncated.
- Money-at-stake as the per-row figure and the default sort.
- Read-first posture: the row opens an EVIDENCE inspector (why / confidence / recommended action), click-to-open, never auto-expanded inline; writes stay off this triage surface.
- Single business, single currency; date range scopes METRICS, not which decisions exist.

WHAT IS WRONG NOW (the problem to fix)
The page stacks too much non-work chrome before the first decision and dumps too many undifferentiated rows once you reach it. Specifically: (1) three context bands — Pulse + Overnight Digest + Readiness — render INSIDE the queue column above row #1 and re-render on every lane, pushing money-at-stake below the fold; (2) staleness and label-coverage are each nagged from 3–4 surfaces (pulse, readiness stack, posture banner, digest header, as-of cluster); (3) six lane tabs and a ~10-control filter toolbar (mixing client VIEW toggles with server QUEUE filters) sit at equal weight; (4) Action Now concatenates 4 separately-ranked engine blocks (Anomalies, cross-adset rollups, Campaigns & Ad sets, Creatives) into one endless scroll with creatives dead last; (5) the Campaigns-XOR-Ad-sets radio severs parent-child context on every drill; (6) the queue is flat — a CBO campaign with 12 ad sets and 40 creatives explodes into ~52 sibling rows; (7) nothing persists, so the page resets to campaign-level cozy with every band expanded each session; and (8) standing explanatory microcopy ("date range scopes metrics not decisions", "filters only narrow the queue", "no fake global rank across engines") is printed as permanent prose.

THE REDESIGN — CONCRETE SPECS

1) DEFAULT STATE / ONE-SCREEN CONTRACT
- The page opens on Action Now only, as a bounded, money-ranked queue directly under the lane tabs. After the brief is collapsed, the first viewport is ALWAYS: lane tabs + money-sorted queue and nothing else — independent of which optional banners this account's state would trigger.
- Bound the queue: render top-N by money-at-stake (~12–15 parents) with an explicit, always-present honest tail: "+N more · +$X at stake below threshold (show all)". Virtualize/paginate; never eagerly render hundreds of rows; never silently truncate.

2) AMBIENT CONTEXT → ONE MORNING BRIEF
- Collapse Pulse + Overnight Digest + Readiness into a SINGLE default-collapsed "morning brief" line/drawer, off the vertical scroll path (do NOT build a persistent 236px rail — it just relocates the clutter and steals grid width). Opened once, then gone.
- The collapsed brief must summarize NON-DR weather too — funnel pacing and brand-safety posture — not only DR bleed, so collapsing it never silently deletes the full-funnel operator's world.
- De-duplicate every repeated status to ONE canonical affordance. Keep exactly one small always-on as-of/staleness stamp (trust check). Move the readiness/label-coverage nag OFF the standing surface and gate it behind actual write-intent — surface it in the inspector at the moment of acting, not four times on load.
- Demote standing explanatory microcopy into tooltips on the relevant control/header (scope-note → tooltip on the date picker; "no fake global rank" → tooltip on the merge toggle). Keep the guarantee, lose the permanent prose.

3) HIERARCHY / LEVEL MODEL
- Replace the Campaigns-XOR-Ad-sets radio with ONE expandable campaign→ad set→creative TREE. Parent-child context is never lost; no mode-swap to find which ad set is leaking. Roll children under parents showing child count + summed money-at-stake + worst child verdict; CBO/ASC campaigns collapse their ad sets by default.
- Add a creative-only VIEW/lens layered over the same tree (a saved focus mode, not a parallel hierarchy).

4) CREATIVES (first-class, on this page)
- Creatives stay ON the Decisions page. A count-chip ("Creatives · 42 need action") is the door IN — it focuses/expands the creative lens in place; it must NEVER route the core cut/scale/refresh decision out to Creative Studio (keep the link to Studio for deep ideation only).
- In the creative lens, group by lifecycle bucket the engine already computes — Winners (scale) / Fatigue (cut/refresh) / Testing (test_more) / Diagnose — each a collapsible section with a live count.
- Creative-native defaults: sort on creative-lifecycle signal (fatigue slope / trajectory / test maturity), NOT raw current spend; keep the thumbnail/hook-frame as a first-class column (the asset IS the evidence); label the ROAS metric with the SELECTED window (7d/14d/28d), never a hardcoded 28d; dedup by creative-asset identity so one asset running in 6 ad sets is ONE row with combined spend/$-at-stake (expand to per-placement), not six leaves.

5) THE QUEUE AS A SORTABLE DATA GRID (with a calm default)
- Convert Action/Watching card stacks into a sortable, column-driven grid: entity | verdict | spend | ROAS | CPA | money-at-stake | age | confidence | funnel-role | delivery-state. Every header sorts; shift-click adds a stable secondary key. Sticky money-at-stake + verdict leading columns; virtualized rows; sticky header. The evidence card becomes the row's click-to-open expanded state, not the default rendering.
- Raw per-row metrics are NEVER abstracted into a summary that replaces them. Roll-ups AUGMENT: a collapsed parent shows a summed money-at-stake subtotal row (pivot style); expanding reveals every underlying raw row. Hoist units ($, %, ×) into column headers; right-align mono numerics.
- The grid DEFAULTS to the bounded top-N feel of "my few things today" (spec 1) so the solo/parachuting operator is not handed an operable spreadsheet on load — power is present, not imposed. Add CSV export respecting the active filter+sort. Add an optional per-user column chooser (a hidden column you chose is fine; a hidden row is not) and optional keyboard triage (j/k move, e open evidence, c claim) to strip per-row action-button chrome.

6) ENGINE SEGMENTATION & CROSS-ENGINE MERGE
- Keep the engines segmented by default: Anomalies / Campaigns & ad sets / Creatives as collapsible sub-sections with live counts, default-collapsing the ones not being worked. Anomalies stay counted separately from the money queue.
- Offer an OPT-IN "merge by money" sort that ranks across collapsed parents by dollars summed (sum or max child) with a PERSISTENT per-row source/engine tag. NEVER fabricate a blended cross-engine confidence rank and never make merge the default.

7) MONEY DEFAULT, FUNNEL FINDABLE, SAFETY ESCALATES
- Money-at-stake stays the default sort and per-row figure. Add funnel-role as a sortable column AND a grouping toggle (Prospecting / Retargeting / Retention / Awareness / Brand). Ship Non-sales EXPANDED by default with a live count (stop the hardcoded collapse). Let brand-safety / policy severity escalate a row into Action Now regardless of dollars.
- Keep the min-spend floor but DEMOTE it from a naked always-on toggle into a saved-view/governed setting. Any active view-filter (especially min-spend) must leave a transparent SUPPRESSION LEDGER receipt: a collapsed one-line "min-spend hid N rows / $X — 3 flagged Awareness/Brand-safety (reveal)" at the tail of its section, tagging suppressed rows by WHY, one click to reveal. This makes aggressive filtering safe: no deliberately-small test or low-spend brand-safety flag is ever silently erased.

8) TEMPORAL DECLUTTER (the biggest calm-at-scale lever beyond roll-up)
- Default Action Now to "new or changed since last session" — rows whose verdict flipped or whose money-at-stake crossed a threshold — with a "show unchanged (N)" tail. Auto-settle rows stable for N days into a collapsed "Settled" tail (build on the existing decision-stability logic). On a stable large account ~80% of rows didn't move; don't re-present them.
- Per-row SNOOZE with a money tripwire: snoozing drops a row from today's queue but ARMS it — it auto-resurfaces the moment its money-at-stake crosses a set threshold or its verdict worsens. Armed, never deleted or dishonestly hidden. Plus a simple per-row handled state.

9) DELIVERY-STATE AWARENESS
- Add a delivery-state column (Learning / Learning Limited / Active / Fatiguing). Auto-defer learning-phase rows out of Action Now into a collapsed "Stabilizing (N) — hold, $X in flight" band, so rows where any edit resets the phase stop shouting a money-at-stake number that invites a harmful action — decluttering and platform-honesty in the same move.

10) TOOLBAR, SAVED VIEWS & OWNERSHIP
- Collapse the ~10-control toolbar to a few essentials (tree/level context, sort, search) plus a single "Filters" disclosure with an active-count badge. Inside it, VISUALLY SEPARATE (a divider) client-only VIEW toggles (min-spend, density, window chip) from server QUEUE-scoping filters — the buyer must always be able to tell what narrows the view vs. what edits the queue.
- Persist sort + filters + level + collapse-state per account so the page reopens in the same calm state. Support two tiers: personal saved views as the floor, plus optional lead-locked pod presets that cascade to buyers with VISIBLY-flagged personal overrides.
- Add per-row claim/assignee state (Mine / Unclaimed / All) as a VIEW filter only — it must NEVER scope the server queue or hide unassigned money — with a "last touched by X at HH:MM" stamp. Hide ALL pod/preset/claim UI entirely on single-operator accounts.
- Get the "+ New campaign" launch button off the triage top bar (keep Run snapshot and the Active / Active+paused / All status filter top-level, one click).

DESIGN INTENT SUMMARY
Two layers, one page: an opinionated, bounded, temporally-filtered DEFAULT that answers "what changed and what's bleeding right now" in the first viewport for the solo/rescuer/ROAS operator — sitting on a fully sortable, exportable, claimable, funnel-aware GRID substrate for the analyst/pod/full-funnel operator, bridged by saved views so each person's calm state persists. Calm comes from collapsing non-work bands, de-duplicating status, rolling up by parent + asset, filtering by change, and gating the nag behind write-intent — NEVER from removing a number, faking a rank, or hiding a row without a receipt.
