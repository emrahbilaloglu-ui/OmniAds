**Root cause (verified): the empty shell and the slowness are the SAME defect.** The Decisions page (`MetaPlatformPage`) loads everything from ONE client query to `/api/meta/decisions-workspace`, which **self-fetches `account-pulse` + `lane-classify` over same-origin HTTP** with an **8s timeout** and the client had **`retry:false`**. Under `next dev --webpack` (Next 16 — webpack was explicitly forced), each route cold-compiles 2–9.4s on first hit; three module compiles (workspace + 2 upstreams) blow the 8s budget → `upstream_failed` 5xx → the whole page shows "Meta briefing could not load" (empty shell). Warm requests are 17–110ms, so it's per-route first-compile.
**FIXED (shipped):** (1) `package.json` `dev`/`dev:local` → `--turbopack` (Next 16 default; `next.config` webpack hook is a trivial cache toggle; reactCompiler works under turbopack) + added `dev:webpack` fallback. **User must restart `npm run dev` to get the speedup.** (2) `MetaPlatformPage` workspaceQuery `retry:false` → `retry:2` w/ backoff (transient timeout self-heals). (3) `decisions-workspace` `WORKSPACE_UPSTREAM_TIMEOUT_MS` 8s → 15s prod / 45s dev (no premature abort). (4) Added a **Retry** button (`data-testid=meta-briefing-retry`) to the error banner.
